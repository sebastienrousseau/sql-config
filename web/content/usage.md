# Usage

`@sebastienrousseau/sql-config` can be consumed across all standard module formats.

## CommonJS

```javascript
const config = require("@sebastienrousseau/sql-config");
console.log(config.presets);
```

## ES Modules

```javascript
import config from "@sebastienrousseau/sql-config";
console.log(config.defaultPreset);
```
